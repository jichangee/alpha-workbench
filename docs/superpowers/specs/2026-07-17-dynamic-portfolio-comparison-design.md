# 动态新增持仓对比设计

## 目标

把现有固定两组的持仓对比升级为动态多组对比。页面默认仍显示两组，用户可点击“新增持仓”加入第三组，并继续增加至最多五组；也可以删除任意一组，但始终至少保留两组。

## 交互设计

- 表单标题根据当前数量显示“编辑 N 组持仓”。
- 持仓编辑区底部新增“+ 新增持仓”按钮。
- 新增组默认名称为下一未使用的顺序名，例如“持仓 3”。
- 新增组默认包含一行空股票代码，权重为 100%，因此单股票组合只需填写代码即可提交。
- 每个持仓卡片增加“删除此持仓”按钮；只剩两组时全部删除按钮禁用。
- 最多五组；达到上限后新增按钮禁用，并显示“最多 5 组”。
- 每个持仓和每个股票行都有稳定内部 ID。删除中间组或编辑代码时，不复用其他组的组件状态。
- 原有日期、股票数量、重复代码和组内权重 100% 校验保持不变。

## 数据与 API

`POST /api/portfolio-comparisons` 的请求和响应结构不变，但 `portfolios` 数量从“恰好 2”调整为“2 至 5”。

后端仍执行：

1. 对所有持仓内的股票代码去重。
2. 每个唯一代码仅下载一次 Yahoo 复权日线。
3. 取全部股票的共同交易日。
4. 每组在首个共同交易日按权重配置，之后不再平衡。
5. 返回每组归一化净值和累计收益、CAGR、波动率、最大回撤。

持仓数量少于 2 或多于 5 时返回 422；行情或共同日期问题继续返回现有 400 错误结构。

## 结果展示

- 持仓摘要卡片随组数自动增加，桌面端两列、窄屏单列。
- 净值图动态生成 2–5 条曲线，使用五种可区分颜色和不同线型。
- 图表说明从“两组起点”调整为“各组起点”。
- 指标表为每组动态增加一列，窄屏保持横向滚动。
- 图表无障碍名称列出当前所有持仓名称。

## 类型与组件边界

- TypeScript 请求和响应中的 `portfolios` 从二元元组改为普通数组。
- `PortfolioComparisonForm` 只负责编辑、数量限制和同步校验。
- `PortfolioComparisonWorkspace` 的请求取消和过期响应保护保持不变。
- `PortfolioComparisonResults` 与图表按响应数组渲染，不假设固定数量。

## 测试与验收

后端新增覆盖：接受三至五组、拒绝六组、跨多组标的仍只下载一次。

前端新增覆盖：

- 默认两组。
- 新增第三组后默认 100% 且可以直接填写股票代码。
- 删除中间组不会改变其他组内容。
- 两组时不能删除，五组时不能继续新增。
- 提交请求包含所有新增组，不再截断。
- 结果摘要、曲线和指标表可渲染第三组。
