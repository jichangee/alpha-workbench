# 持仓对比再平衡点与默认结束日期设计

## 目标

在持仓对比的归一化净值走势图中标记各组合实际执行的再平衡点，并将单策略回测与持仓对比的默认结束日期统一改为本地今天。

本次只修改前端。后端已经在每个组合结果中返回 `rebalanceDates`，不需要新增或改变 API 字段。

## 走势图标记方案

每条组合净值折线使用自身的 ECharts `markPoint` 绘制再平衡点。

选择该方案的原因：

- 标记与所属折线保持同一 series，图例隐藏折线时对应标记一并隐藏。
- 不增加额外散点 series 或图例项目。
- 相比贯穿全图的垂直线，小圆点在月度再平衡场景中产生的视觉噪声更低。

ECharts 模块化注册增加 `MarkPointComponent`。

## 数据映射

对每个组合分别处理：

1. 遍历该组合的 `rebalanceDates`。
2. 在响应顶层 `result.dates` 中查找日期索引。
3. 使用相同索引从该组合的 `equity` 中读取净值。
4. 生成坐标为 `[date, equity]` 的 `markPoint` 数据项。

若日期不在共同交易日列表中，或对应净值不是有限数值，则跳过该标记。`rebalanceDates` 为空时，标记数据为空。

后端已经保证初始配置日不计入 `rebalanceDates`，前端不额外推导或补充再平衡日期。

## 视觉与交互

- 标记为约 8px 的实心圆。
- 标记颜色与所属组合折线颜色一致。
- 使用图表背景色描边，使标记在折线上保持清晰。
- 默认隐藏标记文字，避免月度再平衡在长区间内产生标签拥挤。
- 悬停标记时显示组合名称、事件名称“再平衡”、日期和保留两位小数的净值。
- 多组合在同一天再平衡时，各自在自己的净值坐标显示。
- 如果两个组合曲线与标记完全重合，标记允许自然重合，不人为偏移数据坐标。
- 选择“不再平衡”的组合没有实际日期，因此不显示标记。

## 默认日期

单策略回测和持仓对比都使用相同的默认日期规则：

- 开始日期保持当前规则：当前年份向前五年的 1 月 1 日。
- 结束日期改为本地今天。

例如本地日期为 `2026-07-23` 时，默认范围为 `2021-01-01` 至 `2026-07-23`。

这项修改只影响组件首次初始化时的默认值。结束日期不得晚于今天的限制、用户后续选择、日期字符串格式、行情失效逻辑和 API 请求字段均保持不变。

## 测试与验证

前端测试覆盖：

- 每个组合只生成自己的再平衡点。
- 标记日期与净值坐标来自相同索引。
- 不再平衡或空日期列表不生成标记数据。
- 不存在于共同交易日中的日期被忽略。
- 标记 tooltip 包含组合名称、再平衡、日期和净值。
- 单策略回测默认结束日期为本地今天。
- 持仓对比默认结束日期为本地今天。
- 开始日期规则保持不变。

最后运行完整前端测试和 TypeScript/Vite 生产构建。

## 范围外

- 修改后端再平衡计算或 API。
- 自定义再平衡日期。
- 为标记增加筛选开关。
- 人为错开完全重合的标记。
- 在单策略回测走势图中增加再平衡标记。
