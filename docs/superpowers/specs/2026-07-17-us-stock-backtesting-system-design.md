# 美股可视化回测系统设计

## 目标

构建一套在本机运行、通过浏览器操作的美股日线回测系统。用户无需编写代码即可选择股票或 ETF、配置策略和交易参数、运行回测，并直观看到收益、风险、净值、回撤、买卖点和逐笔交易记录。

首版聚焦“单标的、单策略、做多、日线”场景，优先保证结果可信、交互易懂和模块可扩展，不加入登录、云端同步、实时交易、做空、期权或多资产组合。

## 技术路线

- 前端：React、TypeScript、Vite、ECharts。
- 后端：Python、FastAPI、Pydantic、pandas、NumPy。
- 行情：通过 `yfinance` 自动下载；CSV 导入作为离线和数据异常时的兜底。
- 测试：后端使用 pytest，前端使用 Vitest 与 Testing Library。
- 运行方式：一个本地启动命令同时启动前后端；浏览器访问本机地址。

前后端通过稳定的 JSON 接口通信。回测引擎不依赖 FastAPI 或界面，可以单独测试，也便于后续接入其他数据源和批量回测。

## 用户界面

界面采用单页仪表盘，桌面端为左侧参数面板、右侧结果区，小屏幕下改为上下排列。

### 参数面板

- 数据来源：自动下载或 CSV 上传。
- 标的代码：默认 `SPY`，接受常见美股和 ETF 代码。
- 日期范围：默认最近五个完整年度，结束日期不超过当前日期。
- 策略：买入并持有、均线交叉、RSI 反转、唐奇安通道突破。
- 策略参数：根据策略动态显示，并给出通俗说明与合理默认值。
- 资金与成本：初始资金默认 100,000 美元；佣金默认每笔 0 美元；滑点默认 0.05%。
- 运行按钮：输入有效时可点击；回测期间显示明确的加载状态。

### 结果区

- 摘要指标：期末资产、总收益、年化收益、年化波动率、夏普比率、最大回撤、交易次数、胜率。
- 主图：可切换净值曲线与价格图。价格图叠加策略指标，并标出买卖点。
- 回撤图：以面积图显示历史回撤。
- 基准比较：用同一标的买入并持有作为基准，显示策略与基准的归一化净值。
- 交易明细：显示进出场日期、价格、股数、毛收益、成本、净收益和收益率。
- 空状态和错误状态：解释下一步操作，不显示空白图或技术堆栈。

所有收益率统一显示为百分比，金额统一显示为美元；绿色表示正收益、红色表示负收益，但不只依赖颜色表达含义。

## 策略定义

所有策略只持有一个方向：空仓或全仓做多。信号使用截至当天收盘可知的数据计算，在下一交易日开盘成交，避免未来函数。

### 买入并持有

首个可成交日买入，最后一个交易日按收盘价估值，不强制产生卖出交易。

### 均线交叉

短期简单移动平均线上穿长期简单移动平均线时买入；下穿时卖出。默认周期为 20 日和 50 日，要求短周期小于长周期。

### RSI 反转

RSI 从下向上穿越超卖阈值时买入，从下向上穿越超买阈值时卖出。默认周期 14 日，超卖阈值 30，超买阈值 70，要求超卖阈值小于超买阈值。

### 唐奇安通道突破

收盘价突破此前 N 日最高价时买入，跌破此前 M 日最低价时卖出。默认入场周期 20 日、退出周期 10 日；通道计算排除当前交易日。

## 行情与数据校验

自动下载使用拆股和分红调整后的 OHLCV 日线数据。后端按“代码 + 起止日期”缓存标准化数据；缓存仅是性能优化，删除后可重新下载。

CSV 至少需要日期与 OHLC 列，列名不区分大小写；成交量可选。系统将日期转为交易日索引、按日期升序排列、去重，并拒绝无法解析的日期、非正价格、最高价低于最低价、开盘或收盘价超出当日高低范围等数据。

数据不足以形成策略指标或有效成交时返回可操作的中文提示。自动下载失败时提示用户检查代码、日期或网络，并提供 CSV 导入入口。

## 回测撮合规则

- 初始状态为空仓，使用整数股，不使用融资和杠杆。
- 买入数量为扣除滑点与佣金后现金可购买的最大整数股数。
- 买入成交价为下一交易日开盘价乘以 `(1 + 滑点率)`。
- 卖出成交价为下一交易日开盘价乘以 `(1 - 滑点率)`。
- 每次成交扣除固定佣金；资金不足以购买一股时忽略买入信号并给出警告。
- 期末未平仓持仓按最后一个交易日收盘价估值；交易表将其标为未平仓，不虚构卖出成交。
- 每个交易日记录现金、持仓、总资产、策略净值和基准净值。

## 指标口径

- 总收益：期末资产除以初始资金减一。
- 年化收益：按有效交易日数量使用 252 个交易日年化。
- 年化波动率：日收益率标准差乘以 `sqrt(252)`。
- 夏普比率：默认无风险利率为 0，日均超额收益除以日收益率标准差后乘以 `sqrt(252)`。
- 最大回撤：净值相对历史峰值的最大跌幅。
- 胜率：已平仓且净收益为正的交易数除以已平仓交易总数；没有已平仓交易时显示为不可用。
- 基准：首个可成交日按同样的初始资金买入并持有，但不扣策略设置的交易成本，用于展示市场本身走势。

## 接口与模块边界

后端提供以下接口：

- `GET /api/health`：运行状态。
- `GET /api/strategies`：策略元数据、字段说明、默认值和校验范围。
- `POST /api/market-data/preview`：下载或解析数据并返回范围、行数和少量预览。
- `POST /api/backtests`：校验请求、运行回测并返回完整结果。

核心模块分为行情提供器、数据标准化器、策略信号生成器、撮合引擎、绩效指标计算器和 API 序列化器。策略只生成目标持仓信号，不直接处理资金；撮合引擎只消费行情与信号，不了解具体策略；指标计算器只消费净值与交易记录。

前端分为回测配置、结果摘要、图表、交易表、API 客户端和格式化工具。界面组件不重复实现回测公式。

## 错误处理

- 输入错误返回字段级中文提示，例如“短均线周期必须小于长均线周期”。
- 数据源错误与策略错误使用不同错误码，前端据此展示对应解决方式。
- 后端不向界面返回 Python 堆栈；详细错误保留在本地日志。
- 请求取消或重复点击不会产生并发重复回测。
- 图表遇到空值时断开曲线，不将缺失数据错误填为零。

## 测试与验收

后端测试覆盖：数据标准化与非法 CSV、每种策略的信号时点、下一交易日成交、整数股与交易成本、期末估值、基准曲线，以及所有指标的已知样例和边界情况。

前端测试覆盖：策略切换后的动态字段、字段校验、加载与错误状态、指标格式化、结果渲染和交易表空状态。

端到端验收使用一份固定的小型 OHLCV 数据集，验证从填写参数到显示结果的完整流程。验收标准：

1. 首次安装后可按 README 的命令在本机启动。
2. 输入 `SPY` 与日期范围即可完成自动行情回测。
3. 四种策略均能通过图形界面配置，无需修改代码。
4. 信号不会在产生当天成交，测试能证明不存在一日未来偏差。
5. 修改佣金或滑点会按预期降低期末资产。
6. CSV 导入结果与同一标准化行情的自动下载结果一致。
7. 桌面端和窄屏界面均无横向溢出，关键状态有中文说明。

## 明确不做

首版不包含实时行情、实盘交易、分钟级数据、做空、期权、融资、多标的组合、参数寻优、用户账户、云端部署、税费建模和报告导出。这些能力可在核心引擎稳定后分期增加。
