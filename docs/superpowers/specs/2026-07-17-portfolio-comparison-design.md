# 两组持仓历史走势对比设计

## 目标

在现有美股回测系统中增加独立的“持仓对比”工作区。用户可以编辑两组由多只美股及其初始权重组成的持仓，并在相同历史区间内比较净值走势与核心风险收益指标。

默认示例：

- 持仓 1：50% VOO + 50% QQQ
- 持仓 2：100% SOXX

两组持仓的名称、股票和权重均可编辑；每组可增删股票。

## 核心口径

采用“首日按权重买入、之后不再平衡”的买入持有模型：

1. 从 Yahoo Finance 获取各标的复权日线数据。
2. 取全部标的都存在价格的共同交易日，确保两组曲线逐日严格对齐。
3. 在第一个共同交易日按配置权重、允许碎股地完成初始配置。
4. 后续不交易、不恢复目标权重，各标的权重随价格自然漂移。
5. 将每组初始净值归一化为 100，便于比较不同组合的相对走势。

计算公式：若标的 i 的初始权重为 w_i，复权收盘价为 P_i(t)，则组合归一化净值为：

`V(t) = 100 × Σ[w_i × P_i(t) / P_i(0)]`

这种口径不引入每日再平衡的隐含换手，也不受任意初始资金、整数股和剩余现金影响。

## 用户界面

### 工作区切换

应用顶部增加两个清晰的模式入口：

- 策略回测
- 持仓对比

两个工作区独立，切换不会把持仓编辑参数混入策略回测表单。

### 持仓编辑

持仓对比页左侧/上方展示两个持仓编辑卡片。每个卡片包括：

- 可编辑持仓名称
- 多行“股票代码 + 权重百分比”
- 增加股票按钮
- 每行删除按钮（每组至少保留一只）
- 实时权重合计；不等于 100% 时明确标红
- 共享的开始、结束日期
- “开始对比”按钮

股票代码输入统一转为大写。每组支持 1 至 8 只股票；同组代码不可重复；每项权重大于 0，合计必须为 100%。日期默认最近五年，结束日期不可晚于当天。

行情下载可能涉及多个标的，因此仅在用户点击“开始对比”时请求，不在每次键入时触发网络请求。重复点击会取消上一次尚未完成的请求，过期响应不会覆盖新结果。

### 结果展示

结果区包含：

1. 一张共同横轴的归一化净值折线图，两组起点均为 100。
2. 两组持仓的构成标签。
3. 指标对照表：累计收益、年化收益、年化波动率、最大回撤。
4. 实际共同数据区间与交易日数量。

桌面端优先并排展示，窄屏自动改为上下排列。空状态、加载状态、校验错误和数据错误均在当前工作区内反馈。

## API 设计

新增 `POST /api/portfolio-comparisons`。

请求示例：

```json
{
  "start": "2021-01-01",
  "end": "2026-07-17",
  "portfolios": [
    {
      "name": "持仓 1",
      "positions": [
        { "symbol": "VOO", "weight": 0.5 },
        { "symbol": "QQQ", "weight": 0.5 }
      ]
    },
    {
      "name": "持仓 2",
      "positions": [
        { "symbol": "SOXX", "weight": 1.0 }
      ]
    }
  ]
}
```

约束：

- 恰好两组持仓。
- 每组 1 至 8 个标的。
- 同组股票代码唯一。
- 权重为有限正数，组内合计与 1 的误差不超过 `1e-6`。
- `start <= end <= today`。

响应示例结构：

```json
{
  "start": "2021-01-04",
  "end": "2026-07-16",
  "dates": ["2021-01-04"],
  "portfolios": [
    {
      "name": "持仓 1",
      "positions": [{ "symbol": "VOO", "weight": 0.5 }],
      "equity": [100.0],
      "metrics": {
        "totalReturn": 0.42,
        "cagr": 0.065,
        "annualizedVolatility": 0.17,
        "maxDrawdown": -0.24
      }
    }
  ]
}
```

后端下载请求内所有唯一股票的数据，并对共同交易日至少需要两个观测值。行情不可用、没有共同区间或价格无效时返回可读的 400 错误；结构或权重校验失败返回 422。

## 指标计算

- 累计收益：`末值 / 初值 - 1`
- 年化收益：按首尾共同交易日的实际天数计算 CAGR
- 年化波动率：日收益率样本标准差乘 `sqrt(252)`
- 最大回撤：`min(V(t) / running_max(V) - 1)`

指标使用完整精度计算，由前端统一格式化百分比。区间不足以计算某项指标时返回 `null`，不制造虚假数值。

## 兼容性与边界

- 现有策略回测、CSV 导入、均线滑块和换仓模式保持原样。
- 持仓对比第一版仅使用 Yahoo 行情，不复用单标的 CSV 上传，因为多标的文件映射会显著增加交互复杂度。
- 不提供定期再平衡、股息现金流拆分、税费或交易成本模型；复权价格已用于表达拆股与分红影响。
- 本功能用于历史研究，不构成投资建议。

## 测试与验收

后端覆盖：

- 已知价格序列下的组合净值和指标计算。
- 不同日期索引的共同交易日对齐。
- 权重合计、重复代码、日期和持仓数量校验。
- 行情下载失败及无共同区间的错误映射。

前端覆盖：

- 默认持仓内容。
- 增删股票与权重合计反馈。
- 无效输入阻止提交。
- 正确发送请求并展示加载、失败与成功结果。
- 模式切换不破坏原有回测工作区。
- 图表与指标表正确渲染两组数据。

最终验收运行后端完整测试、前端完整测试、TypeScript 检查和生产构建。
