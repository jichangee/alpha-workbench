# 美股策略回测（本地版）

一个完全在本机运行的美股日线策略回测与资产配置研究工具。前端基于 React、shadcn/ui 和 ECharts，提供中文配置、结果指标、净值/价格/回撤图、交易明细及多组合对比；后端提供 CSV 导入和 Yahoo Finance 行情下载。项目不包含云端部署或托管服务。

> 仅供学习、研究与演示，不构成投资建议、交易建议或任何收益承诺。历史回测结果不代表未来表现；使用者应自行核实数据、策略和风险。

## 前置条件

- Python 3.11 或更高版本（已用 Python 3.13 验证）
- Node.js `^20.19.0` 或 `>=22.12.0`（本机当前 Node 22 符合），以及 npm
- 使用 Yahoo Finance 数据时需要网络；使用 CSV 时可离线运行

## 安装与启动

在项目根目录执行（macOS/Linux）：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e "./backend[dev]"
npm --prefix frontend ci
npm run dev
```

`npm run dev` 会同时启动 FastAPI（`http://127.0.0.1:8765`）和 Vite（终端显示的本地地址，通常为 `http://127.0.0.1:5173`）。按 `Ctrl+C` 会把中断信号转发给两个子进程并停止它们。再次启动时，脚本会先终止经命令行确认属于本项目的残留 FastAPI 进程并等待 8765 端口释放；如果端口由其他程序占用，脚本会保留该进程并明确报错。

Windows PowerShell 请以 `.venv\\Scripts\\Activate.ps1` 激活虚拟环境；其余命令相同。

## 使用方式

1. 选择 Yahoo Finance 或 CSV，并设置标的和日期。
2. 点击“加载行情并开始回测”，完成第一次回测。
3. 之后直接点击策略卡片、拖动参数滑块或调整交易假设；系统会短暂防抖后自动刷新结果，不需要再次确认。

自动回测会复用已经装载的行情，不会重复下载或上传数据。修改行情来源、股票代码、日期或 CSV 文件后，原行情会失效，需要再次点击“加载行情并开始回测”。均线交叉等有关联限制的参数会在拖动时自动保持合法间距。

“卖出处理”可以选择两种模式：

- **卖出后持有现金**：策略卖出主股票后保持现金，等待下一次买入信号。
- **卖出后换仓**：填写一个替代股票代码；主策略卖出时换入替代股票，重新出现买入信号时换回主股票。调仓当天先卖后买，两笔分别计算佣金和滑点。

策略和买入并持有基准都会在第一个交易日开盘建仓；后续策略信号在收盘后确认，于下一交易日开盘执行。换仓模式只使用两只股票共同存在行情的交易日。

切换到“持仓对比”可同时配置 2–5 组资产组合，每组支持 1–8 只股票，并可独立选择不再平衡、每月、每季度或每年再平衡。各组权重必须合计为 100%。

再平衡以所有标的共同交易日为准：系统在周期最后一个共同交易日收盘后恢复目标权重，新权重从下一共同交易日起生效。计算支持碎股，不计组合再平衡交易成本；结果会展示实际再平衡次数和对应日期。

## 测试与生产构建

先激活 `.venv`，再从根目录运行：

```bash
npm run test
npm run build
```

`npm run build` 生成 `frontend/dist`。此目录存在时，FastAPI 启动后会在 `http://127.0.0.1:8765/` 提供前端静态文件；`/api/*` 仍由 API 路由处理。

## CSV 格式

CSV 至少要包含下列列（列名不区分大小写）：

```csv
Date,Open,High,Low,Close,Volume
2024-01-02,470.10,473.67,468.12,472.65,12345678
```

- 必填：`Date`、`Open`、`High`、`Low`、`Close`
- 可选：`Volume`
- 日期必须可解析；价格必须为有限正数。
- 系统按日期升序排列并去重；最高价不得低于最低价，开盘价和收盘价必须位于当日高低价区间内。

## 回测口径与公式

- 策略在第一个交易日开盘买入主标的；后续在收盘后产生目标仓位，于**下一交易日开盘价**成交，避免使用当日尚未知的收盘信息。
- 初始为空仓，只交易整数股，不使用融资或杠杆。
- 买入成交价：`开盘价 × (1 + 滑点基点 / 10,000)`；卖出成交价：`开盘价 × (1 - 滑点基点 / 10,000)`。
- 可买股数：`floor((现金 - 单笔佣金) / 买入成交价)`；每次成交扣除固定佣金。资金不足一股时跳过该买入并给出提示。
- 期末未平仓仓位按最后一个交易日收盘价估值，不强制卖出。
- 默认初始资金为 100,000 美元，单笔佣金为 0 美元，滑点为 5 个基点。
- 总收益：`期末资产 / 初始资金 - 1`；年化指标按 252 个交易日计算；夏普比率默认无风险利率为 0。
- 基准为首个可成交日以相同初始资金买入并持有的标的，不扣除策略设置的交易成本。
